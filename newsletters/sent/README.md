# Sent newsletters

No sent issues have been archived yet. Test emails and unsent drafts do not belong here.

After sending an issue in MailerLite, add the final source HTML and matching metadata:

```text
YYYY-MM-DD-short-title.html
YYYY-MM-DD-short-title.md
```

Use this outline for the metadata file:

```markdown
# Issue title

- Subject:
- Preheader:
- Sent at: YYYY-MM-DD HH:MM timezone
- MailerLite campaign ID:
- Public campaign web URL:
- HTML: [Issue HTML](YYYY-MM-DD-short-title.html)
```

Use MailerLite's public campaign URL, not a recipient's personalized link. Do not add
subscriber lists, credentials, or delivery reports containing personal information.
See the [newsletter workflow](../README.md) for template and browser-preview instructions.
